# 진담 몬스터즈 · 중국 10대 비밀 일기

진담중국어 교재 2권 「중국 10대 비밀 일기」 1~4과와 함께하는 덩어리 몬스터 RPG입니다.

- 학교를 돌아다니며 중국 친구들과 대화하고 '수상한 질문'을 풀어요.
- 풀숲에 들어가면 덩어리 몬스터가 나타나요. 퀴즈를 맞히면 만두볼로 잡아 '덩어리 수첩'에 모아요.
- 틀린 덩어리는 '오답 카드'에 남고, 풀숲에서 다시 만나 맞히면 졸업해요.
- 과마다 '대화 배틀'(대답 고르기·질문 고르기) → 비밀 일기 → 내 문장 만들기 → 교재 미션 순서로 진행해요.
- 4과 뒤에는 도서관에서 진아쌤과 '중간 수사 회의'를 해요.

## 파일
- `js/data.js` 과별 덩어리·대화·일기·미션 (내용 수정은 여기서)
- `js/map.js` 학교 맵·사람·건물
- `js/game.js` 게임 본체 / `js/art.js` 픽셀 그림 / `js/tts.js` 중국어 음성 / `js/sound.js` 소리

저장은 기기 브라우저(localStorage, `jdm1-`)에만 됩니다. 말하기는 스스로 소리 내어 확인하는 방식이며 발음 채점은 하지 않습니다.
