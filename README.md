# 진담 수사대 · 중국 10대 비밀 일기

진담중국어 교재 2권 「중국 10대 비밀 일기」 1~4과와 함께하는 중국어 수사 게임입니다.

## 흐름 (v0.3)
학교를 **칸 단위로 걸어 다니며**(가고 싶은 곳·사람을 누르거나 방향키) 친구와 이야기 → 과마다 **수풀**에 들어가면 쪽지를 든 **헷갈이**가 나타나 **배틀**(중국어 퀴즈로 안개 걷기 → 빨간 도장 쾅) → 도장 6개 → 중국 친구와 **메신저 1분 대화** → 비밀 일기 → 내 문장 만들기(소리 내어 3번) → 교재 미션 안내 → 다음 길의 대나무 문이 열림.
4과까지 해결하면 도서관에서 진아쌤과 **중간 수사 회의**를 해요.

- 배틀에서 틀리면 헷갈이가 쪽지를 들고 도망가요(오답 카드). 수풀을 몇 걸음 걸으면 다시 나타나고, 맞혀야 졸업해요. 메뉴 → 오답 카드에서도 바로 다시 풀 수 있어요.
- 퀴즈 종류: 뜻→중국어, 중국어→뜻, 듣고 고르기, 빈칸 채우기, 문장 조립 (익숙해질수록 어려운 종류가 나와요)

## 파일
- `js/data.js` 과별 덩어리·대화·일기·미션 (내용 수정은 여기서)
- `js/map.js` 걷는 학교 맵(칸)·건물·사람·대나무 문
- `js/svg.js` 사람(4방향 걷기)·과 시작 장면 그림
- `js/game.js` 게임 본체 / `js/tts.js` 중국어 음성 / `js/sound.js` 소리

저장은 기기 브라우저(localStorage, `jdm1-`)에만 됩니다. 말하기는 스스로 소리 내어 확인하는 방식이며 발음 채점은 하지 않습니다.
