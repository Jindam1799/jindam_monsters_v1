# 진담 수사대 · 중국 10대 비밀 일기

진담중국어 교재 2권 「중국 10대 비밀 일기」 1~4과와 함께하는 중국어 수사 게임입니다.

## 흐름
학교 지도에서 장소 누르기 → 그림 장면 속 **단서 쪽지 6장** 찾기 → 쪽지 퀴즈를 맞히면 **빨간 도장**(사건 파일) → 중국 친구와 **메신저 1분 대화** → 비밀 일기 → 내 문장 만들기(소리 내어 3번) → 교재 미션 안내 → 다음 장소 열림.
4곳을 해결하면 도서관에서 진아쌤과 **중간 수사 회의**를 해요.

- 틀린 쪽지는 바람에 날아가 장면의 다른 곳에 숨고(🟠), 다시 풀어 맞혀야 도장을 받아요. 메뉴 → 오답 카드에서도 바로 다시 풀 수 있어요.
- 퀴즈 종류: 뜻→중국어, 중국어→뜻, 듣고 고르기, 빈칸 채우기, 문장 조립 (익숙해질수록 어려운 종류가 나와요)

## 파일
- `js/data.js` 과별 덩어리·대화·일기·미션 (내용 수정은 여기서)
- `js/svg.js` 사람·장면·학교 지도 그림 (쪽지 자리 `spots`)
- `js/game.js` 게임 본체 / `js/tts.js` 중국어 음성 / `js/sound.js` 소리

저장은 기기 브라우저(localStorage, `jdm1-`)에만 됩니다. 말하기는 스스로 소리 내어 확인하는 방식이며 발음 채점은 하지 않습니다.
