# 진담 아침 만두가게

손님의 중국어 주문을 듣고(소리 + 병음 + 뜻) 만두와 차를 빠르게 서빙하는 도트 그래픽 가게 운영 게임입니다.

## 하루 흐름
🌅 **아침 영업** (약 2분 30초, 6:30~8:30) → 💰 **정산** → 🌄 **저녁 활동** 2곳 (시장·강 낚시·농가) → 🌙 **밤** (새 메뉴 연구·가게 꾸미기) → 다음 날

- **아침:** 손님이 중국어로 주문해요 (예: 老板，我要两个肉包子，一杯冰红茶。). 찜기를 눌러 만두를 찌고, 다 쪄지면 눌러서 들고, 손님을 눌러 건네요. 음료는 热(따뜻한 컵)/冰(얼음 컵)을 고르고 주전자를 꾹 눌러 선까지 따라요. 밀크티는 홍차에 우유. 늦으면 손님이 떠나요.
- **틀린 주문:** '다시 익힐 주문'에 남고 다음 날 손님이 같은 주문으로 다시 와요. 맞혀 내면 졸업.
- **단골:** 교재 2권 친구들(李明·陈晨·小雨·王浩)이 와서 교재 대화로 말을 걸어요.
- **저녁:** 시장에서 중국어로 재료 사기(我要… / 要几斤？ / 一共…块), 강에서 낚시(새우·물고기), 농가·산에서 달걀·우유·버섯 모으기.
- **메뉴는 처음엔 肉包子 하나.** 재료를 구하면 밤에 새 메뉴가 열려요: 菜包子, 蘑菇包子, 韭菜鸡蛋饺子, 虾仁饺子 / 豆浆, 绿茶, 奶茶.

## 파일
- `js/md_data.js` 메뉴·음료·재료·숫자·손님·시장·업그레이드 (내용 수정은 여기서)
- `js/data.js` 교재 2권 1~4과 대화 (단골 손님 대화에 사용)
- `js/pix.js` 도트 그림 / `js/md_game.js` 게임 본체 / `js/tts.js` 중국어 음성 / `js/sound.js` 소리

저장은 기기 브라우저(localStorage, `jmd1-`)에만 됩니다.
